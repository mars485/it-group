# IT GROUP — Astro migration

Новая статическая версия сайта разрабатывается отдельно от Django в папке `astro/`.

## Локальная разработка
```bash
cd astro
npm install
npm run dev
```

## Сборка
```bash
npm run build
```

Готовые файлы: `astro/dist/`. Их можно обслуживать обычным Nginx без Docker и Python.

ВНИМАНИЕ: пока не опубликовано. Не перенаправлять DNS и не отключать старую версию до переноса всех страниц, графики, форм и настройки Aspro Cloud. Оригинальные статические ресурсы находятся в корневой папке `static/` исходного проекта; перед публикацией скопировать их в `astro/public/`.
