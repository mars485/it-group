# IT GROUP — сайт на Django

Многостраничный адаптивный сайт веб-студии. Backend: Django 6.1.1, база разработчика — SQLite. Заявки хранятся в Django Admin. Уведомления по email и в Telegram, а также CRM webhook настраиваются в разделе «Настройки сайта»; старые значения из `.env` сохраняются как резервные.

## Карта страниц

| Страница | URL | Задача |
|---|---|---|
| Главная | `/` | Объяснить предложение и получить заявку на бесплатный разбор |
| Услуги | `/uslugi/` | Обзор девяти направлений |
| Разработка сайтов | `/razrabotka-sajtov/` | Лендинги, корпоративные сайты, интернет-магазины |
| Сайты для недвижимости | `/sajty-dlya-agentstv-nedvizhimosti/` | Каталог, фильтры, просмотр, CRM и аналитика |
| Продвижение и реклама | `/prodvizhenie-i-reklama/` | SEO, Яндекс Директ и аналитика |
| Кейсы | `/kejsy/` | Два явно отмеченных демо-концепта, без заявлений о реальных клиентах |

## Концепции первого экрана

1. **Выбранная — «Система продаж».** Слева оффер и два действия, справа — интерфейсная схема «Трафик → сайт → заявка → CRM и следующий контакт». Это сразу показывает позиционирование IT GROUP.
2. **Альтернативная — «Специализация на недвижимости».** Первый экран с каталогом/поиском объектов как визуальным центром, а рядом короткий оффер для агентств. Её можно выбрать, если студия решит сузить основное позиционирование до недвижимости.

## Палитра и визуальный подход

- Фон: графит `#0A0D14`, поверхности `#10151F` и `#141B28`.
- Текст: `#F4F7FB`, вторичный текст `#9AA6B8`.
- Акценты: электрический синий `#417CFF`, бирюзовый `#52D6DC`.
- Направление: крупная типографика, тонкие контуры, карточки, аккуратные градиенты, схема продаж на первом экране.

## Графика сайта

Интерфейс дополнен авторскими SVG-иконками и векторными схемами для главного экрана, услуг, процесса разработки и решений для недвижимости. Иллюстрации хранятся в репозитории и не требуют внешних фотосервисов.

## Установка и развёртывание CMS

Подробная инструкция для ZimaOS/Linux через Docker, обычного VPS без Docker и Python-хостинга находится в [INSTALL.md](INSTALL.md). В ней есть настройка домена, HTTPS, SMTP, админки, обновлений, резервного копирования и разбор частых ошибок.

## Автоустановка на ZimaOS / Linux через Docker

Репозиторий публичный — скачайте его на сервер без GitHub-аккаунта и SSH-ключа:

```bash
git clone https://github.com/mars485/it-group.git
cd it-group
```

Затем в каталоге проекта запустите:

```bash
chmod +x install.sh
./install.sh
```

Установщик проверит Docker Compose, попросит домен или IP сервера, сгенерирует `SECRET_KEY`, подготовит `.env` с правами `600`, соберёт контейнер и запустит сайт. При вводе IP тестовый сайт доступен по `http://IP:8000`; домен работает через HTTPS за reverse proxy (например, Nginx Proxy Manager), направленный на порт `8000`. Если оставить поле пустым, сайт будет доступен локально на сервере по `http://localhost:8000`.

SQLite и загруженные файлы хранятся в Docker volumes и остаются после пересоздания контейнера. После первого запуска создайте пользователя админ-панели:

```bash
docker compose exec web python manage.py createsuperuser
```

Обновить сайт после изменения кода: `docker compose up -d --build`. Посмотреть логи: `docker compose logs -f web`.

Исходный код и история Git публичны. Не добавляйте в репозиторий `.env`, пароли, токены, `SECRET_KEY`, базу данных, пользовательские файлы и резервные копии. Секреты храните на сервере; если секрет уже попадал в Git, замените его даже после удаления файла.

## Запуск локально

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env       # Windows: copy .env.example .env
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Откройте `http://127.0.0.1:8000/`. Панель управления сайтом и заявки доступны в `/admin/`.

## Панель управления сайтом

После создания пользователя командой `createsuperuser` войдите в `/admin/`. Панель позволяет редактировать:

- название бренда, публичный URL, логотип, контакты, ссылки на мессенджеры, цвета и ID Яндекс Метрики;
- тему публичного сайта (тёмную или светлую), шрифт (DM Sans, Manrope, Inter, системный либо Georgia) и общий размер текста (90–120%). Эти параметры меняет администратор; переключатель для посетителей не отображается;
- отдельный email для заявок, SMTP и уведомления в Telegram, а также CRM webhook. Сохранённые значения из `.env` используются, пока соответствующее поле интеграции в админке пустое;
- пункты основного меню и их порядок;
- SEO Title и Description для каждой страницы;
- содержимое любой страницы: поле HTML может полностью заменить стандартный макет выбранной страницы;
- услуги, этапы работы, FAQ, функции сайтов недвижимости и направления продвижения;
- пакеты работ и кейсы/концепты. Цены и результаты можно оставить пустыми, пока нет подтверждённых данных;
- входящие заявки и UTM-метки.

Страница входа и интерфейс Django Admin оформлены в фирменном стиле IT GROUP и адаптируются для мобильных экранов. Раздел «Настройки сайта» доступен только суперпользователю: в нём находятся SMTP-пароль и токен бота. Эти секреты хранятся в базе и попадают в её резервные копии. Для смены секрета введите новый; пустое поле сохраняет прежний, а флажок удаления очищает его. Загруженный логотип сохраняется в томе медиа.


Структурированные записи услуг, FAQ и этапов уже добавляются при миграции базы данных. Чтобы изменить внешний вид, выберите тему, шрифт и размер текста в «Настройках сайта»; там же задаются отдельные HEX-цвета фона тёмной и светлой темы в формате `#417CFF`. Тёмная тема остаётся темой по умолчанию для существующих установок. В поле содержимого страницы разрешён HTML, поэтому доступ к панели следует выдавать только доверенным сотрудникам.

## Настройка перед публичным запуском

1. Установить `SECRET_KEY`, `DEBUG=False`, `ALLOWED_HOSTS`, `CSRF_TRUSTED_ORIGINS` и адрес в `SITE_URL`. Серверные параметры безопасности и путей к данным остаются в `.env`.
2. Заполнить в «Настройках сайта» публичные контакты, URL, логотип, тему, шрифт, размер текста и цвета.
3. Указать там адрес для заявок и параметры SMTP, если нужна почта; токен бота и ID чата, если нужен Telegram; CRM webhook, если используется CRM.
4. Указать ID Яндекс Метрики в админке; счётчик и события формы/кликов включатся автоматически.
5. Добавить там ссылки Telegram/WhatsApp, телефон, город, часы и реквизиты.
6. Проверить политику обработки данных с юристом и заполнить оператора, контакт и дату.
7. Настроить HTTPS, резервные копии БД и медиа, почтовый транспорт и production-сервер.
8. Проверить интеграцию CRM с конкретным API, защиту загрузок и требования к персональным данным.

## SEO и аналитика

Есть уникальные Title/Description для страниц, canonical, Open Graph, favicon, семантические заголовки, внутренняя перелинковка, динамические `sitemap.xml` и `robots.txt`, JSON-LD Organization/Service/FAQ. UTM-метки сохраняются вместе с заявкой. События предусмотрены для отправки формы и кликов по телефону/мессенджерам; Метрика активируется при наличии ID. Региональные посадочные страницы добавляются отдельными маршрутами после выбора городов.

## Что получить от владельца

- телефон, email, Telegram, WhatsApp, город/адрес и график;
- юридическое лицо/ИП или ФИО оператора персональных данных, реквизиты и адрес для политики;
- финальный домен, фирменные логотипы и предпочтения по знаку;
- цены или принцип коммерческого расчёта и реальные сроки по каждому пакету;
- реальные кейсы, ссылки, изображения, технологии и подтверждённые результаты;
- Яндекс Метрика ID, сервис коллтрекинга, CRM и данные API/webhook;
- подтверждённые правила договора, оплаты, поддержки и гарантий.
